# 功能概述

组织负责人平时需要维护组织里的成员账号（加人、改资料、重置密码、停用账号等）。当负责人出差、休假或事务较多时，可以让本组织的一名成员来代办这些事，这个被指定的成员就是**负责人助理**。

- **组织负责人**：创建组织时平台自动生成的账号，是组织的最高管理者，一个组织只有一个负责人。
- **负责人助理**：由负责人从**本组织成员**中指定的代办人，可以在「组织架构」中代替负责人管理本组织及下级组织的成员和组织信息。

本文截图均可点击查看大图。

开始操作前，请先分清三件容易混淆的事：

1. **负责人助理不是角色**。它不会出现在「角色」的可选项里，而是一个独立的身份。授权成功后，成员列表的角色列会多出一个黄色的「负责人助理」标签。
2. **负责人助理不会扩大数据范围**。助理仍然只能看到自己数据权限内的电站和设备，助理身份只增加「组织架构」里的管理操作权限。
3. **只有负责人本人能授权和撤销**。助理本人看不到「负责人助理」页签，也不能给其他人授权。

## 1.能做什么，不能做什么

| 操作 | 负责人助理 |
| --- | --- |
| 查看组织架构 | 可以，范围为本人所在组织及下级组织 |
| 新增成员、修改成员信息、启用/停用账号、重置密码 | 可以，限本组织及下级组织成员 |
| 转移成员、删除成员 | 可以，但组织负责人不能被转移或删除 |
| 新建下级组织 | 可以 |
| 修改、转移、删除下级组织 | 可以 |
| 修改本人所在组织（本组织）的组织信息 | 不可以 |
| 操作本组织的负责人、本组织的其他负责人助理 | 不可以 |
| 授权或撤销负责人助理 | 不可以，页签对助理不可见 |
| 查看更多的电站、设备数据 | 不可以，数据权限不随助理身份扩大 |

> 说明：助理在「组织架构」里的操作权限与负责人基本一致，但上面「不可以」的几项是硬性限制，界面上对应按钮会置灰或直接不显示。
>
> 「测点组」页签是否可见、能否维护测点组，由成员自己的角色决定，不受负责人助理身份影响。

## 2.授权前的准备

授权前请逐项确认，任何一项不满足都会导致授权失败或对方登录后看不到菜单：

1. **使用组织负责人本人的账号登录**。助理、普通成员都没有授权入口。
2. **被授权人已经是本组织成员**。负责人助理只能从「本组织成员」中选择，下级组织的成员不能直接授权。
3. **被授权人的角色包含「组织架构」菜单权限**。这是最容易漏掉的一步：
   - 负责人可以在「成员列表 → 修改 → 角色」中，为该成员勾选一个已经包含「组织架构」菜单权限的角色（负责人只能勾选自己拥有的角色）；
   - 如果可选角色里没有这样的角色，请联系平台管理员：在角色管理中为该角色勾选「组织管理 → 组织架构」菜单，或由管理员直接分配合适的角色。
   - 授权弹窗也会提示这一点：**需要手动分配包含组织架构模块菜单权限的角色**。
4. **负责人不能把自己设为助理**。下拉框中不会出现负责人本人。

## 3.授权负责人助理

### 3.1进入「负责人助理」页签

1. 登录 Solarhub Web 平台。
2. 在左侧菜单点击「组织管理 → 组织架构」。
3. 在右侧页签栏点击「**负责人助理**」。

<a href="/../../zh/photo/docs/organization/assistant-tab.webp" target="_blank" rel="noopener"><img src="/../../zh/photo/docs/organization/assistant-tab.webp"></a>

> 注意：「负责人助理」页签**只有组织负责人本人能看到**。如果你看不到这个页签，说明当前登录账号不是负责人，或者你已经被设为助理（助理不能管理助理）。

> 该页签始终管理**你所在的组织**，不会随左侧组织树切换。也就是说，即使左侧选中了某个下级组织，这里显示的仍然是本组织的助理清单。

### 3.2选择成员并授权

1. 点击「**选择本组织成员**」下拉框。
2. 输入成员的姓名、用户名或邮箱进行搜索（下拉项显示为「姓名（用户名）」），然后选中该成员。
3. 点击右侧的「**授权助理**」按钮。

<a href="/../../zh/photo/docs/organization/assistant-select.webp" target="_blank" rel="noopener"><img src="/../../zh/photo/docs/organization/assistant-select.webp"></a>

> 下拉框中只列出本组织中**还不是助理**的成员，负责人本人不会出现。已经授权过的人不会再出现在候选里。

### 3.3确认授权

1. 弹出确认框，内容为「将用户设置为负责人助理？（注意：需要手动分配包含组织架构模块菜单权限的角色）」。
2. 核对成员无误后，点击「**确定**」；如需放弃，点击「取消」。

<a href="/../../zh/photo/docs/organization/assistant-confirm.webp" target="_blank" rel="noopener"><img src="/../../zh/photo/docs/organization/assistant-confirm.webp"></a>

### 3.4授权成功

页面顶部提示「操作成功」，该成员会出现在「负责人助理」页签的列表中，显示用户名、姓名、角色、邮箱和手机号。

<a href="/../../zh/photo/docs/organization/assistant-success.webp" target="_blank" rel="noopener"><img src="/../../zh/photo/docs/organization/assistant-success.webp"></a>

> 授权、撤销后，平台会清除该成员的登录状态。请通知对方**重新登录**，新身份才会生效；对方当前如果正在使用平台，会被强制退出，建议提前沟通。

## 4.授权后如何确认

授权完成后，可以从两个地方确认：

### 4.1「负责人助理」页签

在「负责人助理」页签的列表中能看到该成员，说明授权已生效。列表右侧的「撤销助理」用于取消授权，详见下一节。

### 4.2「成员列表」中的标签

切换到「成员列表」页签，该成员所在行的「角色」列会多出一个黄色的「**负责人助理**」标签。原来的角色标签仍然保留，说明助理身份是叠加在原有角色之上的，不会替换原有角色。

<a href="/../../zh/photo/docs/organization/assistant-tag.webp" target="_blank" rel="noopener"><img src="/../../zh/photo/docs/organization/assistant-tag.webp"></a>

如果对方重新登录后仍然看不到「组织管理」菜单，通常是**角色缺少「组织架构」菜单权限**。处理方式：

1. 在「成员列表」中找到该成员，点击操作列的「修改」。
2. 在「成员信息修改」面板中找到「**角色**」，勾选包含「组织架构」菜单权限的角色（下图为示例，实际角色名称以平台配置为准）。
3. 点击「保存」，然后让对方重新登录。

<a href="/../../zh/photo/docs/organization/assistant-role.webp" target="_blank" rel="noopener"><img src="/../../zh/photo/docs/organization/assistant-role.webp" width="600" height="738"></a>

> 修改角色只影响菜单和操作权限，不会取消「负责人助理」身份。保存后，成员列表中会同时显示角色标签和黄色的「负责人助理」标签。

## 5.撤销负责人助理

当对方不再需要代办时，由负责人撤销其助理身份：

1. 进入「组织管理 → 组织架构 → 负责人助理」页签。
2. 在列表中找到该成员，点击操作列的「**撤销助理**」。

<a href="/../../zh/photo/docs/organization/assistant-revoke.webp" target="_blank" rel="noopener"><img src="/../../zh/photo/docs/organization/assistant-revoke.webp"></a>

3. 在确认框中点击「确定」。页面提示操作成功后，该成员的「负责人助理」标签消失。

撤销后：

- 对方仍然是本组织的正常成员，**不会被删除**，原有角色、测点组、数据权限都保持不变；
- 对方会立即失去组织架构中的管理操作权限；
- 平台会清除对方的登录状态，需要重新登录后生效。

## 6.常见问题

**Q1：我在「组织架构」里看不到「负责人助理」页签？**

只有组织负责人本人能看到。请确认当前登录账号是组织的负责人；如果你本人就是助理，是看不到该页签的。

**Q2：下拉框里找不到要授权的成员？**

请确认：① 对方是本组织成员，不是下级组织成员；② 对方还不是负责人助理；③ 对方不是负责人本人。以上任一情况都不会出现在候选列表中。

**Q3：授权成功了，但对方登录后看不到「组织管理」菜单？**

助理身份只负责「能不能管理组织」，能不能看到菜单还取决于角色。请按第 4.2 节为该成员分配包含「组织架构」菜单权限的角色，然后让对方重新登录。

**Q4：负责人助理能看到更多电站或设备数据吗？**

不能。助理身份不会改变数据权限，对方看到的电站、设备和参数范围仍由他自己的数据权限、角色和测点组决定。

**Q5：助理可以再授权其他人当助理吗？**

不可以。只有负责人本人能授权或撤销助理，助理看不到「负责人助理」页签。

**Q6：把助理转移到其他组织后，助理身份还在吗？**

不在。助理身份绑定在原组织上，成员被转移到其他组织时会自动取消，需要由新组织的负责人重新授权。

**Q7：撤销助理会把成员一起删掉吗？**

不会。撤销只清除「负责人助理」身份，成员账号、角色和权限都保留。

## 7.注意事项

- 授权和撤销都会让目标成员**强制退出并需要重新登录**，操作前请先与对方沟通，避免对方正在操作时被中断。
- 一个组织可以设置多个负责人助理，请按实际工作需要授权，避免权限扩散。
- 组织负责人不能被删除或转移，只能随组织一起被清理；助理也不能操作本组织的负责人。
- 助理在新增成员、修改成员时，只能授予自己拥有的角色和测点组，不能授予超出自己权限范围的内容。
