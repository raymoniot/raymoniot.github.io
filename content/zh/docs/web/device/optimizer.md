# 功能概述

优化器（MLPE）用于对光伏组串中的每块组件做独立的最大功率点跟踪，通常作为子设备挂在采集器下，由采集器采集并上报数据到平台。

## 1.设备列表

<img src="/../../zh/photo/docs/device/optimizer/device-list.png">

设备列表可以查看在线、故障、离线和全部的设备信息，上方的状态标签会同时显示各状态的设备数量，点击标签可以只看该状态的设备。

列表中会显示序列号、别名、所属电站、所属采集器、时区、数据更新时间等，点击序列号进入优化控制器详情页。

## 2.优化器控制器详情页

<img src="/../../zh/photo/docs/device/optimizer/detail-enter.png">

从设备列表中的设备可以进入设备详情页

<img src="/../../zh/photo/docs/device/optimizer/detail.png">

优化器控制器详情页展示优化器控制器的信息和优化器的开关状态。

页面顶部显示设备名称和最近一次数据更新时间（含设备所在时区），右侧的「报警」「解绑」是常用操作，其余操作在「…」菜单中。页面内容分两块：

- **基本信息**：控制器 MAC 地址、快速开关、优化器数量、实时功率、累计总电量
- **优化器**：控制器下每台优化器一条记录，显示名称（别名或序列号）和实时功率，颜色代表状态——绿色为打开、红色为关闭、灰色为离线；卡片右上角是对应的颜色图例，用于对照颜色含义，不是操作按钮。点击某台优化器可以进入它自己的详情页
