# 功能概述

设备中心按设备类型分为采集器、逆变器、电池系统、优化器、智能电表等页面。每个页面都可以查看该类型下的全部设备、按状态筛选和搜索，并进入单个设备的详情页查看信息和历史数据。

设备数据由采集器上报：现场的逆变器、电池、电表、优化器等作为**子设备**挂在采集器下，由采集器统一采集并上报数据。因此设备列表里除了设备自身信息，还会显示它所属的**电站**和**采集器**，点击即可跳转。

设备列表和详情页的通用操作：

- **列表**：状态标签显示全部、在线、故障、离线的设备数量，点击可筛选；搜索框按序列号、别名等关键字搜索；点击序列号进入设备详情页
- **详情页**：顶部显示设备名称、最近数据更新时间（含时区）和收藏、刷新按钮，右上角是「报警」「解绑」，其余操作在「…」菜单中，下方是设备信息卡片和历史数据图表
