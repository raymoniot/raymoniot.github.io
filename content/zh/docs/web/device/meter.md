# 功能概述

电表用于计量电站的并网、负载等电量数据，通常作为子设备挂在采集器下，由采集器采集并上报数据到平台。

## 1.设备列表

<img src="/../../zh/photo/docs/device/meter/device-list.webp">

设备列表可以查看在线、故障、离线和全部的设备信息，上方的状态标签会同时显示各状态的设备数量，点击标签可以只看该状态的设备。

列表中会显示序列号、别名、所属电站、所属采集器、时区、数据更新时间等，点击序列号进入电表详情页。

## 2.电表详情页

<img src="/../../zh/photo/docs/device/meter/detail-enter.webp">

从设备列表中的设备可以进入设备详情页

<img src="/../../zh/photo/docs/device/meter/detail.webp">

电表详情页展示电表信息和微逆设备。

页面顶部显示设备名称和最近一次数据更新时间（含设备所在时区），右侧的「报警」「解绑」是常用操作，其余操作在「…」菜单中。页面内容分两块：

- **基本信息**：智能电表系列号、A 相电压、A 相电流、瞬时总有功功率、瞬时总无功功率、电网频率、正向有功总电能、反向有功总电能
- **微逆设备**：该电表下微逆设备的数量和每台微逆（SN0、SN1……）的序列号
