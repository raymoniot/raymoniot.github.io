# 功能概述

运维中心用于跟踪平台上发生的异常并把它们变成可跟进的工单：

- **事件中心**：汇总平台上已发生告警的电站和设备，可以按条件检索事件，并针对某条事件[新建工单]({{< ref "ticket/list" >}} "工单列表")
- **工单系统**：由[工单看板]({{< ref "ticket/dashboard" >}} "工单看板")、[工单列表]({{< ref "ticket/list" >}} "工单列表")和[客服团队]({{< ref "ticket/team" >}} "客户团队")组成——看板看整体处理情况和趋势，列表处理具体工单，客服团队决定工单由谁来处理

事件来自设备上报的告警和故障；工单可以由事件、电站或设备发起，也可以在 App 上由终端用户提交，两类数据相互关联，便于形成"发现问题 → 派单 → 处理 → 评分"的闭环。
