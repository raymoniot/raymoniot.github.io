# 功能概述

工单看板用于快速了解当前工单的整体情况：顶部是四个关键指标，中间是工单趋势图，下方是待办和评分统计。

<img src="/../../zh/photo/docs/ops/ticket/ticket.png">

- **未解决**：尚未解决的工单数
- **逾期**：已经超过首次响应或关闭截止时间仍未处理的工单数，需要优先处理
- **处理中**：正在处理中的工单数
- **未指派**：还没有指派处理人的工单数

**今日趋势**对比昨天和今天的工单数量变化，鼠标悬停可以看具体时段的数值，用于判断当天的处理压力。

**待办**列出需要当前账号处理的工单，点击可以直接进入该工单。

**评分**统计用户对工单处理结果的评价（正面、负面、中立、未评），反映服务质量。

工单系统的操作记录

点击右上角「最近活动」打开抽屉，按时间倒序展示工单的操作记录，包括工单编号、操作时间、操作人和变更的状态（如打开、待定、已解决、已关闭），便于追溯谁在什么时候处理了哪张工单。
