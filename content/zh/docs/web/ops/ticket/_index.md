# 功能概述

工单系统用于接收和处理用户提出的问题，包括三部分：

- **[工单看板]({{< ref "dashboard" >}} "工单看板")**：整体处理情况、今日趋势、待办和评分统计
- **[工单列表]({{< ref "list" >}} "工单列表")**：所有工单的明细，可以进行状态变更、修改和评分
- **[客服团队]({{< ref "team" >}} "客户团队")**：维护处理工单的团队及其主要成员

工单可以由[事件中心]({{< ref "../events" >}} "事件中心")的事件、电站详情页或设备详情页发起，也可以由终端用户在 App 上提交。
