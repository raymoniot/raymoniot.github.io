# 功能概述

报表中心用于按时间维度查看和导出统计数据，分两个页面：

- **[电站报表]({{< ref "total" >}} "汇总数据")**：按业务类型、电站统计发电量、收益等
- **[设备报表]({{< ref "total" >}} "汇总数据")**：按设备类型、序列号统计设备的运行数据

两个页面都支持选择报表种类（日、月、年、总）和时间范围，查询结果可以导出为 Excel 表格，用于对账和汇报。报表中能看到哪些电站和设备取决于账号的数据权限。
