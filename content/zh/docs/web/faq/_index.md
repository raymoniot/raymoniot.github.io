# 功能概述

这里汇总客户在现场和日常使用中最常遇到的问题，按主题分篇说明：

- [网络搜索工具]({{< ref "1.network-tools" >}} "网络搜索工具")：如何用工具搜索并配置采集器（修改服务器地址等）
- [采集器首次上电不在线]({{< ref "2.device-offline" >}} "采集器首次上电不在线")：采集器安装后平台看不到数据时的排查步骤

如果按文档排查后仍未解决，请收集设备序列号和现象，联系我们的技术支持。
