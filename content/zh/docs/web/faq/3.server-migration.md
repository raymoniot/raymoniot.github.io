# 功能概述

**服务器迁移**指把采集器的数据上报地址从一台服务器换成另一台，例如：设备原本上报到 A 服务器（自有/贴牌环境），需要改为上报到 B 服务器（公版环境）。

这个过程**不需要重刷固件**：采集器里存了**两个服务器地址**，并用一个“地址选择”测点决定当前用哪一个，改完选择后**下发软复位重启**采集器即可生效。

采集器上相关的四个测点：

| 测点名称 | 作用 | 示例编号* |
|---|---|---|
| **Server Url1** | 地址1（服务器 A） | 613000 |
| **Server Url2** | 地址2（服务器 B） | 613100 |
| **Server选择** | 选择使用哪个地址：值 **1** → 用地址1，值 **2** → 用地址2 | 613200 |
| **软复位** | 下发值 **1** 后采集器重启，新地址才会生效 | 853000 |

> \* 测点编号随**设备型号和固件版本**不同而不同（例如同功能在另一款固件上是 610100 / 610200 / 610300 / 850000），请以页面上实际显示的编号为准，**认名称比认编号更可靠**。

## 操作步骤

### 1. 确认设备在两个环境都已入库

迁移前先保证设备在**目标服务器**（要迁往的环境）已完成入库，同时原环境里也要能查到这台设备，否则迁移后可能两头都看不到。

入库方法：**设备中心 → 采集器 → 导入**（可用批量导入模板一次导入多台）。

<img src="../../../../photo/docs/device/collector/import-more.webp">

### 2. 设备上电并保持在网

采集器上电后，在**工具箱 → 远程交互**中能找到它，状态为**在线**。

<img src="../../../../photo/docs/toolkits/remote-enter.webp">

### 3. 修改服务器地址与地址选择

在远程交互列表中找到该采集器，点击操作列的**参数设置**：

<img src="../../../../photo/docs/toolkits/remote-send.webp">

在「测点参数设置」中修改：

<img src="../../../../photo/docs/toolkits/remote-set1.webp">

1. **填写/核对地址**：把要使用的两个服务器地址分别填到 **Server Url1**、**Server Url2**（地址通常形如 `xxx.example.com`，为服务器域名或 IP）
2. **修改 Server 选择**：要迁到地址1 就把“Server选择”改成 **1**，要迁到地址2 就改成 **2**——**选哪个哪个生效**
3. 点击右下角**批量设置**下发（可以一次提交多个测点）

### 4. 下发软复位重启采集器

地址改完后必须**重启采集器**才会生效：把“软复位”测点也一起设置，值为 **1**，然后下发。

> 这一步是关键：只改 Server 选择、不做软复位的话，采集器仍然会用原来的地址上报。

### 5. 确认指令已下发成功

在**操作日志**中确认指令结果：处理结果为 `Order sent to device.`、响应代码为 0 表示已成功下发到设备。

<img src="../../../../photo/docs/toolkits/remote-logs1.webp">

### 6. 在目标环境确认设备在线

采集器重启后会按新的地址上报数据。到**目标服务器/平台**上查看该设备是否显示**在线**、数据是否开始更新，在线即迁移完成。

## 注意事项

- **必须下发软复位**，否则地址切换不会生效
- 需要迁移多台设备时，可以用**工具箱 → 批量操作**里的参数设置，一次给多台设备下发同样的地址与选择
- 「Server 选择」只决定**用哪个地址**，它不会自动修改地址内容；迁移到新服务器时，通常要先把新地址写进对应的 Server Url
- 切换前请确认目标服务器已准备好接收该设备（设备已在目标环境入库、平台账号有对应权限）
- 若设备处于离线状态，远程指令会下发失败，请先排查设备在线情况（参见[采集器首次上电不在线]({{< ref "2.device-offline" >}} "采集器首次上电不在线")）
- 除本方法外，也可以用**网络搜索工具**在局域网内直接改服务器地址（适用于现场调试），见[网络搜索工具]({{< ref "1.network-tools" >}} "网络搜索工具")
