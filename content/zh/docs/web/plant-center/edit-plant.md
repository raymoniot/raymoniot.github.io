# 功能概述

修改电站用于更新电站的基本信息、位置、干系人和照片。创建电站时填写有误或后期发生变化（例如联系人变更、需要授权新的访客），都在这里调整。

## 1.修改电站入口

<img src="/../../zh/photo/docs/edit-plant/edit-plant.png">

在电站列表右侧操作列点击「修改」（也可以从电站详情页进入）

<img src="/../../zh/photo/docs/edit-plant/edit-plant1.png">

修改电站步骤请参考[完善电站信息]({{< ref "/create-plant/#2完善电站信息" >}} "创建电站")

需要注意：

- **业务类型**不可修改，电站建好后业务类型固定
- 只有电站业主（以及具备相应权限的组织管理员）可以修改或删除电站，被授权为访客的账号只能查看
- 在「干系人」中新增访客邮箱，即可把电站授权给其他账号，效果与[访客授权]({{< ref "/guest-access" >}} "访客授权")一致
