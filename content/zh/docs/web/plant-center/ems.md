# 功能概述

商业电站页面用于管理业务类型为商业电站（EMS）的电站，页面结构与[光伏系统]({{< ref "/pvs" >}} "光伏系统")完全一致：上方是电站概览，下方是电站列表和电站地图，右上角可以添加电站、进入系统大屏，点击电站进入详情页。

各板块的具体说明参考对应章节，本节只列出与光伏系统、户用储能的差异。
