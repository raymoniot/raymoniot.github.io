# 功能概述

创建电站是把一个电站录入平台，并填写它的装机容量、地址坐标、业主与访客等信息。创建后电站会出现在电站列表中，绑定采集器后即可看到发电数据。

## 1.创建入口

<img src="/../../zh/photo/docs/add-plant/add-plant.webp">

在电站中心对应业务类型页面的右上角点击「添加电站」，按向导分四步完成：基本信息 → 地理位置 → 干系人 → 照片。

## 2.完善电站信息

### 2.1填写基本信息

<img src="/../../zh/photo/docs/add-plant/add-plant1.webp">

- **业务类型**：决定电站属于光伏系统、电池系统、户用储能还是商业电站，创建后电站会出现在对应页面，不能修改
- **电站类型**：如家庭户用等，用于进一步区分场景
- **电站名称**：必填，建议填写便于识别和搜索的名称
- **并网类型**：如全额上网、自发自用等
- **建站日期**：电站的投运日期，不填也可以创建
- **度电收益、总成本、货币**：用于计算和展示电站收益，不填写时收益相关指标按 0 计算
- **光伏装机容量（kWp）/ 储能装机容量（kWh）**：按所选业务类型显示，光伏类电站填光伏装机容量，电池系统、储能类电站还要填储能装机容量，这两项是对应业务类型下的必填项，用于计算满发小时等指标，请按实际填写

### 2.2选择地理位置

<img src="/../../zh/photo/docs/add-plant/location.webp" width="30%">

允许网站进行定位可以快速获取当前位置

<img src="/../../zh/photo/docs/add-plant/add-plant2.webp">

在地图上选择位置获取坐标信息作为电站位置

电站坐标会用于电站地图的展示，建议填写准确。

### 2.3添加干系人（访客）

<img src="/../../zh/photo/docs/add-plant/add-plant3.webp">

输入访客邮箱即可将电站授权给平台其他账号从而使其拥有电站访问权限

- **电站业主**：默认为当前登录账号，业主可以修改和删除这个电站
- **电站访客**：被授权账号可以在自己的电站列表中看到该电站并查看数据，但不能修改或删除电站，权限范围详见[访客授权]({{< ref "/guest-access" >}} "访客授权")
- **联系人、联系电话**：记录电站的现场联系人信息

### 2.5提交

<img src="/../../zh/photo/docs/add-plant/add-plant5.webp">

创建成功即可在电站列表中看到电站，同时也可以在列表操作一列中进行电站的[修改]({{< ref "/edit-plant" >}} "电站编辑")和删除

电站创建完成后，下一步是[添加采集器]({{< ref "/add-logger" >}} "添加采集器")，采集器上报数据后电站才会有实时功率、发电量等数据。
