# 功能概述

访客授权是把电站的查看权限授予平台上的其他账号。被授权的账号（访客）可以在自己的电站列表中看到这个电站并查看它的数据，但不能修改或删除电站——修改、删除、添加采集器等管理操作仍然只有电站业主可以操作。

一个电站可以添加多个访客，删除访客即收回该账号的查看权限。

## 1.授权入口

在[修改电站]({{< ref "/edit-plant" >}} "修改电站")中，通过完善电站信息中的[添加干系人]({{< ref "create-plant/#23添加干系人访客" >}} "修改电站")进行授权

在「电站访客」一行输入平台账号的邮箱并点击添加，该账号即获得这个电站的查看权限；也可以在创建电站时的第 3 步「干系人」中直接添加。
