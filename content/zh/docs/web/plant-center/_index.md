# 功能概述

电站中心按业务类型分为光伏系统、电池系统、户用储能、商业电站等页面，每个页面的结构一致：

- **电站概览**：把当前账号数据权限下该业务类型的电站数据汇总成几块指标（实时功率、电量、社会效益、在线电站等），点击右上角「系统大屏」可以全屏展示
- **电站列表 / 电站地图**：列表按状态（在线、故障、离线）查看电站，支持按电站名称、地址、电站业主等关键字搜索；地图按地理位置展示电站的在线状态和分布
- **添加电站**：创建新的电站，详见[创建电站]({{< ref "/create-plant" >}} "创建电站")
- **电站详情页**：点击电站进入，查看该电站的图表、设备、告警、布局和资料，并可以添加采集器、新建工单、发电修补等

电站数据来自绑定到该电站的采集器及其子设备，因此新建电站后还需要[添加采集器]({{< ref "/add-logger" >}} "添加采集器")，电站才会开始有数据。

列表和详情页中能看到哪些电站，取决于账号的数据权限（见「组织管理 → 组织架构」）以及是否被授权为访客（见[访客授权]({{< ref "/guest-access" >}} "访客授权")）。
