# 功能概述

工具箱面向运维和调试场景，提供以下工具：

- **固件管理**：维护各设备类型的 OTA 固件，并做访问授权、兑换码分发
- **批量操作**：对多台设备批量做固件升级、参数设置、指令透传，任务化跟踪，失败设备可重做
- **测点查询**：按序列号查询设备最新一包上报的测点数据，用于排查设备上报情况
- **远程交互**：对采集器单设备下发指令透传、参数设置、固件升级，并查看操作日志
- **生产测试**：按测试标准对设备做生产/出厂测试，自动导出测试报告
- **通知公告**：向 Web 或 App 推送公告消息

工具箱中的操作大多会下发到真实设备，执行前请确认选择的设备无误。
