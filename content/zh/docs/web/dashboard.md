# 功能概述

数据看板是登录后的默认首页，用于从宏观视角查看当前账号数据权限下的电站情况：电站总数和各类型电站的数量、以及电站的地理分布。

页面右上角还有两个快捷入口：

- **我的工单**：进入[工单列表]({{< ref "ops/ticket/list" >}} "工单列表")，查看与自己相关的工单
- **我的收藏**：快速进入已关注的电站（在电站列表点击电站名称前的星标即可关注）

## 业务使用

- 作为运维商或安装商，需要了解自身公司名下关联电站的分类数量情况和设备分布情况，改页面展示电站总数，以及平台中各种类型电站的数量

- 在地图中显示不同地区电站的分布情况，地图可以进行比例缩放，分布情况会根据缩放比例进行不同维度的分布展示
