## Solarhub Web概述

Solarhub Web提供光伏、风电、储能等综合能源监控服务，面向中大型电站、设备厂商、运维商、户用电站业主提供专业、高效的综合能源云监控平台服务。





## 拥有Solarhub账号

![overview](../../photo/docs/overview.png)

- 体验账号：为了方便您快速体验Solarhub的功能，我们开通了客户体验账号，您可以向商务对接负责人沟通后输入体验账号及密码即可体验Solarhub。**目前支持主流的浏览器，推荐您使用Chrome58、Firefox49、IE9以上版本**。

  操作步骤：通过访问Solarhub（Web），选择“登录方式”后，输入体验账号和密码即可登录Solarhub。



## 业务板块简介

登录平台后，左侧菜单按业务板块划分，常用的几个是：

- **数据看板**：电站总数与分布的地图总览，见[数据看板]({{< ref "dashboard" >}} "数据看板")
- **电站中心**：按业务类型（光伏系统、电池系统、户用储能、商业电站等）管理电站，见[电站中心]({{< ref "plant-center" >}} "电站中心")
- **设备中心**：按设备类型（采集器、逆变器、电池系统、优化器、智能电表等）管理设备，见[设备中心]({{< ref "device" >}} "设备中心")
- **运维中心**：查看设备告警事件并处理工单，见[运维中心]({{< ref "ops" >}} "运维中心")
- **报表中心**：按电站、设备导出日月年总统计数据，见[报表中心]({{< ref "report" >}} "报表中心")
- **工具箱**：固件管理、批量操作、测点查询、远程交互、生产测试、通知公告，见[工具箱]({{< ref "toolkits" >}} "工具箱")
- **组织管理**：组织、成员账号与测点组管理，见[组织管理]({{< ref "organization" >}} "组织管理")

平台还提供内部管理、系统管理等管理员使用的板块，一般由平台运维人员使用。

第一次使用建议先看[快速开始]({{< ref "quickStart" >}} "快速开始")，按"采集器配网 → 采集器入库 → 创建电站 → 添加采集器 → 查看数据"的顺序走一遍。
