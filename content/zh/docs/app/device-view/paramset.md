# 功能概述

在设备详情页右上角菜单中点击「参数设置」，可以对当前设备下发可写参数（不同设备类型支持的参数不同）。

<img src="/../../zh/photo/docs/app/device/deviceview-set.png" style="margin-right: 50px" width="300">

## 步骤

1. 在设备详情页点击右上角菜单
2. 选择「参数设置」
3. 在参数页面选择/填写需要下发的参数
4. 点击下发按钮执行（支持一次下发多个参数）

## 注意事项

- 参数会直接下发到现场设备，请确认设备在线、参数值正确
- 下发结果可以在 Web 平台的设备详情页（或设备操作日志）中查看
- 设备离线时下发会失败或超时
