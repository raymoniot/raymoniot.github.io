# 功能概述

用户设备视角进入后默认打开的是**设备详情**的实时数据页，展示这台设备当前的工作状态和参数。

<img src="/../../zh/photo/docs/app/view/device-root.png" style="margin-right: 50px" width="300">

## 页面内容

不同设备类型展示的参数不同，以电池系统为例：

- **SN**：设备序列号
- **SOC 状态**：剩余电量、总电压等
- **健康状态 SOH**：电池健康度、循环次数
- **系统功率**：当前功率与充放电状态（充电中/放电中）
- **总电压、电池电流**等实时参数

## 常用操作

- 右上角菜单：刷新、设备切换、添加采集器、配网、参数设置、设备别名、解绑设备
- 底部标签在 实时、统计、我的 之间切换
- 下拉页面可以刷新数据

> 说明：账号能看到的参数受**测点组**限制，如果这里看不到参数或参数不全，请在 Web 平台的「组织管理 → 组织架构」（见 Web 文档的[组织架构](../../web/organization/tree/)）中检查测点组授权。
