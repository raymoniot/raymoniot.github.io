## Solarhub App概述

Solarhub App 提供光伏、风电、储能等综合能源监控服务，您可以在手机上随时查看电站和设备的数据、处理告警、调试采集器。

App 最大的特点是**三种使用视角**：同一个账号可以在「我的 → 切换视角」中切换视角，不同视角进入 App 后看到的第一个页面、底部导航和可用的功能都不一样。

| 视角 | 适合谁 | 进入后落在 | 底部标签 |
|---|---|---|---|
| **专业顾问** | 设备制造商、经销商、安装人员或专业顾问 | 电站列表（全部电站） | 电站 / 设备 / 事件 / 我的 |
| **用户电站** | 以电站为焦点关注数据的用户 | 某个电站的概览 | 概览 / 统计 / 布局 / 我的 |
| **用户设备** | 以设备为焦点关注数据的用户 | 某个设备的详情 | 实时 / 统计 / 我的 |

- 三种视角的说明与切换方法，见[切换视角]({{< ref "my/switch" >}} "切换视角")
- 各视角下的界面与功能差异，见[专业顾问视角]({{< ref "manager-view" >}} "专业顾问视角")、[用户电站视角]({{< ref "plant-view" >}} "用户电站视角")、[用户设备视角]({{< ref "device-view" >}} "用户设备视角")

如果是第一次使用 App，建议先看[快速开始]({{< ref "quickStart" >}} "快速开始")。
