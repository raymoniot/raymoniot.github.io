## 视角说明

专业顾问视角面向设备制造商、经销商、安装人员或专业顾问：这类使用者需要管理平台上**所有的电站和设备**，并处理平台上发生的告警事件。

在「我的 → 切换视角」中选择「专业顾问」后，App 进入这个视角。

## 进入后的界面

进入专业顾问视角后，首先看到的是**电站列表**（当前账号数据权限内的全部电站），底部有四个标签：

<img src="/../../zh/photo/docs/app/view/manager-root.png" style="margin-right: 24px" width="300">

<img src="/../../zh/photo/docs/app/view/manager-devicelist.png" style="margin-right: 24px" width="300">

<img src="/../../zh/photo/docs/app/view/manager-eventlist.png" style="margin-right: 0px" width="300">

| 标签 | 内容 |
|---|---|
| **电站** | 全部电站列表，支持按名称搜索、按电站类型和在线状态筛选，可进入电站概览并创建电站 |
| **设备** | 全部设备列表，支持按采集器、设备状态筛选和按序列号搜索，可进入设备详情 |
| **事件** | 平台上的事件列表，支持按事件代码查询，可查看事件详情 |
| **我的** | 账号相关功能（用户信息、修改密码、多语言、配网、OTA助手、本地调试等） |

这是三种视角中**唯一带「事件」标签**的视角；电站页右上角菜单提供 创建电站、切换电站、添加采集器、配网、设备列表。

## 与另外两个视角的差别

- 专业顾问视角可以在**多个电站之间横向查看**，也可以跨电站查看全部设备与事件
- 设备详情右上角菜单只有 参数设置、设备别名、解绑设备；如果需要**添加采集器、配网、切换设备**，请使用[用户设备视角]({{< ref "../device-view" >}} "用户设备视角")
- 如果只需要关注单个电站或单个设备，切换[用户电站视角]({{< ref "../plant-view" >}} "用户电站视角")或[用户设备视角]({{< ref "../device-view" >}} "用户设备视角")后界面更聚焦
