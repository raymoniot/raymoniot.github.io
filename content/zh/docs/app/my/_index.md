# 功能概述

「我的」页面在三种视角下内容一致，包含账号相关的全部功能：

<img src="/../../zh/photo/docs/app/my/info.png" style="margin-right: 50px" width="300">

- **切换视角**：在专业顾问、用户电站、用户设备三种视角之间切换，见[切换视角]({{< ref "switch" >}} "切换视角")
- **用户信息**：查看账号信息
- **修改密码**：修改登录密码
- **账户注销**：注销当前账号（不可恢复）
- **多语言**：切换 App 界面语言
- **配网**：给采集器配置网络，见[配网]({{< ref "config" >}} "配网")
- **OTA助手**：设备和采集器的固件升级（OTA）
- **本地调试**：通过蓝牙连接设备进行本地调试，见[本地调试]({{< ref "bleDebug" >}} "本地调试")
- **缓存清理**：清理 App 本地缓存
- **ORG工具箱**：组织相关的工具箱
- **关于**：查看 App 版本号（如 V2.5.2）

> 说明：切换视角只改变 App 的界面和可用功能，不影响账号本身的数据权限；账号能看到哪些电站、设备和参数，由 Web 平台上配置的数据权限、角色和测点组决定。
