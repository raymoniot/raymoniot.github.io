## 什么是视角

App 提供三种使用视角，同一个账号可以随时切换。视角决定进入 App 后**看到什么、能做什么**：进入的首页面、底部导航和可用的功能入口都不一样。

<img src="/../../zh/photo/docs/app/my/switch.png" style="margin-right: 50px" width="300">

| 视角 | App 内的说明 | 适合谁 |
|---|---|---|
| **专业顾问** | 我是设备制造商、经销商、安装人员或专业顾问 | 需要管理平台上所有电站和设备的人 |
| **用户电站** | 以电站为焦点关注数据 | 只关心某个电站运行数据的人（如电站业主） |
| **用户设备** | 以设备为焦点关注数据 | 只关心某个设备数据与调试的人 |

## 切换方法

1. 在 App 底部菜单栏选择「我的」
2. 点击「切换视角」
3. 在三个视角卡片中选择需要的视角，当前生效的视角会带蓝色边框和右下角的对勾
4. 切换后 App 会重新进入该视角的首页面（专业顾问进入电站列表，用户电站进入电站概览，用户设备进入设备详情）

## 三种视角的界面与功能差异

| | 专业顾问 | 用户电站 | 用户设备 |
|---|---|---|---|
| 进入后落在 | 电站列表（全部电站） | 某个电站的概览 | 某个设备的详情 |
| 底部标签 | 电站 / 设备 / 事件 / 我的 | 概览 / 统计 / 布局 / 我的 | 实时 / 统计 / 我的 |
| 设备列表 | 「设备」标签展示全部设备，可按采集器、设备状态筛选，支持按序列号搜索 | 电站页右上角菜单 → 设备列表，只展示该电站下的设备 | 设备详情右上角菜单 → 设备切换 |
| 事件 | 有「事件」标签，可查看平台上的事件 | 无 | 无 |
| 电站相关操作 | 创建电站 / 切换电站 / 添加采集器 / 配网 / 设备列表 | 同左 | 无 |
| 设备详情操作 | 参数设置 / 设备别名 / 解绑设备 | — | 刷新 / 设备切换 / 添加采集器 / 配网 / 参数设置 / 设备别名 / 解绑设备 |

各视角的详细说明见：

- [专业顾问视角]({{< ref "manager-view" >}} "专业顾问视角")
- [用户电站视角]({{< ref "plant-view" >}} "用户电站视角")
- [用户设备视角]({{< ref "device-view" >}} "用户设备视角")

需要说明的是，「我的」页面（用户信息、修改密码、多语言、配网、OTA助手、本地调试、缓存清理、ORG工具箱、关于等）在三种视角下内容一致，切换视角不会影响账号本身的数据权限。
