# Function Overview

Plant Statistics is used to view the historical data of this plant: you can switch the statistical dimension by day, month, year, or all, and select a specific date or time range.

<img src="../../../../photo/docs/app/plant/history1.webp" style="margin-right: 0px" width="300">

## Steps

1. On the plant overview page, tap the "Statistics" tab at the bottom
2. Select the statistical dimension: day, month, year, or all (the selectable time range changes accordingly when you switch the dimension)
3. Switch the date to view through the date selector; the chart will show the data curve of that time range
4. Tap the zoom button in the upper right corner of the chart to view it in full screen
5. Tap a point on the curve with the mouse/finger to view the specific value at that point

## Page Content

- Chart area: the data curve of the selected dimension
- Below the chart: summary indicators such as peak power and full-load hours

> Note: after entering the details page of a plant in the Professional Consultant Perspective, there is also the same "Statistics" tab, with the same usage.
