# Function Overview

Bind the logger to the current plant, and only then will the plant start to have data. The entry is in the menu in the upper right corner of the plant overview page.

<img src="../../../../photo/docs/app/view/plant-logger.webp" style="margin-right: 24px" width="300">

<img src="../../../../photo/docs/app/view/plant-logger2.webp" style="margin-right: 0px" width="300">

## Steps

1. On the plant overview page, tap the menu in the upper right corner and select "Add Logger"
2. After entering the scan page, scan the QR code on the logger with your phone; if you cannot find the QR code on the logger, you can tap "Didn't find the serial number?" on the page to view the description of the QR code location
3. You can also tap the keyboard icon on the scan page to enter the manual input page, enter the logger serial number, and tap "Add Device"
4. After successful addition, the logger is bound to this plant

> Note: the logger must first be imported on the platform; a serial number that has not been imported will report a verification failure. For the import method, see [Add Logger]({{< ref "../manager-view/plant/logger" >}} "Add Logger").
