# Function Overview

The Plant User Perspective focuses on only one plant at a time. When you need to view another plant, use "Switch Plant" to switch.

<img src="../../../../photo/docs/app/plant/switch1.webp" style="margin-right: 24px" width="300">

<img src="../../../../photo/docs/app/plant/switch3.webp" style="margin-right: 0px" width="300">

## Steps

1. On the plant overview page, tap the menu in the upper right corner
2. Select "Switch Plant"
3. Select the plant to switch to in the plant list, and you will enter that plant's overview page

> Note: the list only shows plants within the data permissions of the current account. If you need to view all plants and devices across plants, switch to the [Professional Consultant Perspective]({{< ref "../manager-view" >}} "Professional Consultant Perspective").
