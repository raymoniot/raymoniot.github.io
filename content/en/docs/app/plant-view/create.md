# Function Overview

You can also create a plant in the Plant User Perspective: the entry is in the menu in the upper right corner of the plant overview page.

<img src="../../../../photo/docs/app/plant/create1.webp" style="margin-right: 24px" width="300">

<img src="../../../../photo/docs/app/plant/create2.webp" style="margin-right: 0px" width="300">

## Steps

1. On the plant overview page, tap the menu in the upper right corner and select "Create Plant"
2. Fill in basic information such as the plant name
3. Tap the save button in the upper right corner to complete creation
4. After successful creation, you can switch to the newly created plant in "Switch Plant"

> For more complete instructions on creating a plant (including fields such as plant type, installed capacity, and location), see [Create Plant]({{< ref "../manager-view/plant/create" >}} "Create Plant").
