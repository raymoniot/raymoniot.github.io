1. Click OTA Assistant in the "My" interface at the bottom of the APP
2. The firmware redeemed with the redemption code will be displayed in the list
3. Click Redeem in the upper right corner to redeem the firmware with the redemption code. For redemption code generation, refer to the Web
4. Click Firmware Upgrade to enter the upgrade interface
