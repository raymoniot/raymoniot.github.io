## Template engine rendering

<img src="../../../../photo/docs/app/my/ble.png" style="margin-right: 20px" width="230">

<img src="../../../../photo/docs/app/my/ble1.png" style="margin-right: 20px" width="230">

<img src="../../../../photo/docs/app/my/ble2.png" style="margin-right: 20px" width="230">

<img src="../../../../photo/docs/app/my/ble3.png" style="margin-right: 20px" width="230">

1. Click local debugging in the "My" interface at the bottom of the APP
2. After the APP enters the local debugging function for the first time, it will automatically download the template rendering engine to load the template data. The template engine will iterate and have more powerful functions, which can be updated at any time in subsequent use

## Template Management

<img src="../../../../photo/docs/app/my/ble4.png" style="margin-right: 50px" width="300">

<img src="../../../../photo/docs/app/my/ble5.png" style="margin-right: 50px" width="300">

1. When you first enter local debugging, the latest template will be automatically downloaded. Click the template button to update the latest template.
2. You can also download the template by scanning the template QR code in the upper right corner

## Local debugging

<img src="../../../../photo/docs/app/my/ble9.png" style="margin-right: 50px" width="300">

<img src="../../../../photo/docs/app/my/ble10.png" style="margin-right: 50px" width="300">

<img src="../../../../photo/docs/app/my/ble11.png" style="margin-right: 50px" width="300">

Connect the device via Bluetooth. After the connection is successful, you can read parameters, set parameters, and upgrade the firmware.

<img src="../../../../photo/docs/app/my/ble12.png" style="margin-right: 50px" width="300">

<img src="../../../../photo/docs/app/my/ble13.png" style="margin-right: 50px" width="300">

<img src="../../../../photo/docs/app/my/ble14.png" style="margin-right: 50px" width="300">

1. Parameter reading: read device parameters
2. Parameter setting: modify specified parameters
3. Firmware upgrade: perform OTA operation on the device

<img src="../../../../photo/docs/app/my/ble15.png" style="margin-right: 50px" width="300">

Local debugging is still possible when the APP is not logged in
