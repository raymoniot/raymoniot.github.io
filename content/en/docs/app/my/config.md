1. Go to "My" at the bottom of the APP and click Network Configuration to enter the network configuration interface and prepare for network configuration
2. To configure the network, you need to turn on Bluetooth, connect to 2.4GhzWIFi, and authorize Bluetooth WiFi and other permissions to the APP, otherwise the network configuration may fail.
3. Add a device in the upper right corner, add a device by scanning the code or manually entering the serial number
4. If the device enters the network configuration state, it will appear to be checked. Otherwise, it cannot be checked. Check the device to enter the Wi-Fi selection interface

2. The network is being configured. Generally, it takes 10s-20s to complete the configuration.
