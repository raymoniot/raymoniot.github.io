### Steps

1. Select a plant in the plant list to enter the plant overview interface
2. Select Layout at the bottom to enter the layout interface
3. Create a layout
4. By default, corresponding components will be created based on all devices under the plant

### Steps

1. You can freely adjust the position of components by dragging them or edit them individually through the edit below

2. You can see the component number in the edit component interface, adjust the direction and angle of the component, and click Save after adjustment

3. You can add and delete components in the layout interface (if you cannot add components, it means the components are full)

4. Save the current layout through the Save button in the upper right corner

### Function Overview

1. Click the arrow in the lower right corner to open the power curve

2. Click the curve to select a time point to view the power situation at that moment. The data in the component will also change accordingly, and you can see the power situation of each device at a certain time point

3. The refresh button in the lower right corner of the layout can quickly reset the layout perspective, and the pencil-shaped button is used to enter the layout editing interface

4. The upper arrow can switch the layout data of the previous day or the next day, and click the time to manually select the time
