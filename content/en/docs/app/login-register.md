Registration information overview:

- **Email**: used for account login and registration security code acquisition
- **Security code**: Enter a valid email address to send the security code
- **Username**: Platform users can use it as the platform account to log in
- **Password**: Platform account password
- **Time zone**: Account time zone. The platform will select different time zone offsets for time display based on the different account time zones
- **Installer information**: No need to change by default. If you have special needs, contact the installer
