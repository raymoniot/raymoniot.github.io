## Solarhub App Overview

Solarhub App provides comprehensive energy monitoring services for photovoltaic, wind power and energy storage systems, so that you can check plant and device data, handle alarms and debug loggers on your phone at any time.

The most distinctive feature of the App is its **three usage perspectives**: the same account can switch between perspectives in "Me → Switch Perspective". After switching, the first page you see, the bottom navigation and the available functions are all different.

| Perspective | Who it is for | Page you land on | Bottom tabs |
|---|---|---|---|
| **Professional Consultant** | Equipment manufacturers, dealers, installers or professional consultants | Plant list (all plants) | Plant / Device / Event / Me |
| **Plant User** | Users who focus on the data of a plant | Overview of one plant | Overview / Statistics / Layout / Me |
| **Device User** | Users who focus on the data of a device | Details of one device | Realtime / Statistics / Me |

- For the description of the three perspectives and how to switch, see [Switch Perspective]({{< ref "my/switch" >}} "Switch Perspective")
- For the interface and function differences of each perspective, see [Professional Consultant Perspective]({{< ref "manager-view" >}} "Professional Consultant Perspective"), [Plant User Perspective]({{< ref "plant-view" >}} "Plant User Perspective") and [Device User Perspective]({{< ref "device-view" >}} "Device User Perspective")

If you are using the App for the first time, start with [Quick Start]({{< ref "quickStart" >}} "Quick Start").
