### Steps

1. Select a plant in the plant list to enter the plant overview interface
2. Select **Statistics** at the bottom to enter the statistics interface (this tab was named "History" before the version update)
3. You can view the data at a certain time point by **pressing** the chart
4. You can switch the data of the previous day or the next day by using the arrow above, and click the time to manually select the time; the zoom-in button in the upper right corner of the chart allows full-screen viewing
