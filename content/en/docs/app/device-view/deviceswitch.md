# Function Overview

The Device User Perspective focuses on only one device at a time. When you need to view another device, use "Switch Device".

<img src="../../../../photo/docs/app/view/device-switch.png" style="margin-right: 50px" width="300">

## Steps

1. On the device details page, tap the menu in the upper right corner
2. Select "Switch Device"
3. Select the device you want to view in the device list, and you will enter the details page of that device

> Note: this is **an entry unique to the Device User Perspective**. There is no "Switch Device" in the Professional Consultant Perspective, where you need to select another device again in the "Device" tab.
