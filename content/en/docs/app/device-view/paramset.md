# Function Overview

Tap "Parameter Settings" in the menu in the upper right corner of the device details page to deliver writable parameters to the current device (different device types support different parameters).

<img src="../../../../photo/docs/app/device/deviceview-set.png" style="margin-right: 50px" width="300">

## Steps

1. On the device details page, tap the menu in the upper right corner
2. Select "Parameter Settings"
3. Select or enter the parameters to be delivered on the parameter page
4. Tap the deliver button to execute (multiple parameters can be delivered at one time)

## Notes

- Parameters are delivered directly to the device on site; please make sure the device is online and the parameter values are correct
- The delivery result can be viewed on the device details page of the Web platform (or in the device operation log)
- Delivery fails or times out when the device is offline
