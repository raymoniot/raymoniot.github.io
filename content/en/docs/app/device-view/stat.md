# Function Overview

Device Statistics is used to view the historical data curves of this device.

<img src="../../../../photo/docs/app/view/device-stat.png" style="margin-right: 50px" width="300">

## Steps

1. On the device details page, tap the "Statistics" tab at the bottom
2. Select the statistical dimension (such as day, month, year, or all) and the date
3. The chart shows the data curve of this device in the selected time range; you can tap a data point to view the specific value

> Note: the selectable parameters are also limited by the measurement groups authorized to the account.
