# Function Overview

Organization management is used to maintain the organizations, member accounts and measurement groups on the platform:

- **[Organizational Structure]({{< ref "tree" >}} "Organizational Structure")**: manage subordinate organizations and member accounts on the organization tree, and manage the **measurement groups** that control which parameters members can see

The visible range and operation ability of a member account are decided by three items together:

- **Data Permissions**: which plants and devices can be seen
- **Role**: which menus and operations can be used
- **Measurement Group**: which parameters can be seen on the device details page
