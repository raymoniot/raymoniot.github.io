### 1.1 Add Members

<img src="../../../../photo/docs/organization/member-add.png">

Add members to the selected organization

<img src="../../../../photo/docs/organization/member-add1.png" width="700" height="550">

Definition of the data permissions for new members:

- **Only for oneself**: Newly added members can only see data within **their** permissions
- **People in the same organization**: Newly added members can see data within **their** own authority, and can also see data within **other members in the same organization**
- **People in the same organization & subordinate organizations**: Newly added members can see data within **their** own authority, and can also see data within **other members in the same organization** and **other members in subordinate organizations**
