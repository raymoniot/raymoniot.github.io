# Function Overview

Organizational structure is used to manage the organizations, member accounts and measurement groups on the platform. The left side shows the organization tree; after selecting an organization, you can switch between **Member List**, **Organization Information** and **Measurement Group** on the right.

<img src="../../../../photo/docs/organization/enter.webp">

- **Member List**: view and manage the member accounts under the current organization
- **Organization Information**: view and modify the current organization, and create subordinate organizations
- **Measurement Group**: divide the device measurement points into groups to control which parameters a member can see on the device details page

The organizations you can see and operate in the tree depend on your roles and permissions; subordinate organizations and their members are created and maintained by the superior organization.

## 1. Member List

<img src="../../../../photo/docs/organization/member-list.webp">

View all members under the current organization, including status, user name, name, role, email and phone number. The row of the organization's person in charge is highlighted.

- You can filter members by role, or search by user name / phone / email / name
- The switch in the Status column enables or disables a member account; a disabled member cannot log in to the platform
- In the Operation column you can modify a member, transfer the member to another organization, reset the password or delete the member

### 1.1 Add Members

<img src="../../../../photo/docs/organization/member-add.webp">

Add members to the selected organization

<img src="../../../../photo/docs/organization/member-add1.webp" width="700" height="550">

You need to fill in the current timezone, user name, name, gender, password, password confirmation and email. The password must be between 5 and 20 characters, and the user name cannot be modified after it is saved.

Definition of the data permissions for new members:

- **Only for oneself**: Newly added members can only see data within **their** permissions
- **People in the same organization**: Newly added members can see data within **their** own authority, and can also see data within **other members in the same organization**
- **People in the same organization & subordinate organizations**: Newly added members can see data within **their** own authority, and can also see data within **other members in the same organization** and **other members in subordinate organizations**

Besides data permissions, you also need to choose for the member:

- **Role**: determines which menus and operations the member can use after logging in
- **Measurement Group**: determines which parameters the member can see on the device details page, see section 3 of this chapter
- **Event Grade Available**: the member can see alarms at the selected grade and higher (Low / Warning / Serious)

## 3. Measurement Group

<img src="../../../../photo/docs/organization/point-enter.webp">

### 3.1 What is a measurement group

A device usually reports dozens to hundreds of measurement points (voltage, current, temperature, alarm and other parameters), but different positions need to focus on different parameters. A measurement group is "a set of measurement points" and is used to control **which parameters a member can see on the device details page**.

It is used in two steps:

1. On the **Measurement Group** page, divide the measurement points into one or more measurement groups, for example "Basic parameters", "O&M parameters", "Commissioning parameters";
2. In the **Member List**, select the measurement groups for the member.

After a member logs in and opens the device details page, the page only shows the parameters of the measurement groups authorized to that member; unauthorized parameters do not appear. The parameters that can be selected in the **History** chart on the device details page are limited by the measurement groups as well.

Note that a measurement group only controls **the visibility of the parameters on the device details page**. Which plants and devices a member can see is decided by **Data Permissions**, and which menus and operations the member can use is decided by the **Role**.

There are two sources of measurement groups: the built-in measurement groups provided by the platform (see 3.2) and the measurement groups you create under your own organization (see 3.3).

### 3.2 Built-in measurement groups

There are two measurement groups in the list that are provided by the platform and do not need to be created by yourself: **All test point groups** and **End User Group**.

**All test point groups: used for "no parameter restriction"**

- It is a measurement group preset by the platform, which contains all the measurement points of all device types: whatever device types and measurement points are defined on the platform are included
- Its purpose: when authorizing a member, simply select it, which is equivalent to not restricting parameters. The member can see all parameters on the device details page without assigning measurement points one device type at a time. It fits administrators, O&M staff and other roles that need the complete device data
- It belongs to the platform root organization, so it only appears in the measurement group list when you manage the root organization; it is not shown in the list of subordinate organizations. If a subordinate organization also needs a full authorization, it can create a measurement group under its own organization and assign the required measurement points to it
- It can be renamed, adjusted or deleted like an ordinary measurement group

**End User Group: used for the parameters that end users see by default**

- It is a built-in measurement group of the platform, and every organization has its own End User Group
- Its purpose: end users (accounts that register themselves in the App) automatically join the End User Group of their organization after registration, so the administrator does not need to authorize them one by one. Therefore the measurement points assigned in the End User Group are the parameters these accounts can see after logging in to the platform; to adjust the visible parameters of all end users, you only need to change this one group
- It only supports **Distribution Of Measurement Points**, cannot be renamed or deleted, and cannot be selected in the measurement group selector of the **Member List** (it is shown greyed out in the selector)

### 3.4 Measuring point allocation

<img src="../../../../photo/docs/organization/point-set.webp">

<img src="../../../../photo/docs/organization/point-set1.webp">

Click **Distribution Of Measurement Points** on a row to configure the measurement points for this measurement group. The left side shows the **Unassigned** measurement points and the right side shows the measurement points already **Assigned** to the group.

1. Select the device type at the top (device type / brand / model, three levels); measurement points are defined per device type, so the measurement points of each device type are selected separately;
2. Select the measurement points to be assigned on the left and click **Add**; the measurement points move to the assigned list on the right;
3. Select assigned measurement points on the right and click **Remove**; the measurement points move back to the left;
4. Click **Close** to return to the measurement group list. The changes above are saved immediately and need no extra confirmation.

Meaning of the columns in the list:

- **Point ID**: the number of the measurement point within its device type
- **Alarm type**: a measurement point marked with YES is an alarm type measurement point
- **Name**: the name of the measurement point

### 3.5 Authorize measurement groups to a member

In the **Member List**, click **Add Members** or the modify button on a row, select the measurement groups to authorize in the **Measurement Group** item and click **Save**.

<img src="../../../../photo/docs/organization/member-update1.webp" width="700" height="550">

- Selected measurement groups are highlighted and multiple selection is supported
- If a member is not authorized for any measurement group, no parameter is shown on the device details page after the member logs in; modify the member again to add the authorization
- **All test point groups** and **End User Group** are built-in measurement groups of the platform, see 3.2; the **End User Group** cannot be selected in member authorization
- You can only select the measurement groups owned by the current account (created by yourself or authorized to you); other measurement groups do not appear in the list

### 3.8 FAQ

<img src="../../../../photo/docs/organization/point-no-param.webp">

**After logging in, an account cannot see any parameter on the device details page**

The device details page only shows the parameters in the measurement groups authorized to the account. If this happens, check according to the account type:

1. **If the account is a person in charge account**: check whether the measurement groups selected for this account have been assigned the measurement points of the **target device type** (the device type of the current device). Measurement points are assigned to measurement groups per device type, so when the measurement points of that device type are missing, the details page shows no parameter.
2. **If the account is an end user account**: check whether the **End User Group** of the organization the account belongs to has been assigned the measurement points of the corresponding device type. End users automatically join the End User Group of their organization and do not select measurement groups themselves, so this group is where to check.

After handling the corresponding case above, let the account enter the device details page again and the parameters will be shown; if they are still not shown, please contact the platform administrator for help.
