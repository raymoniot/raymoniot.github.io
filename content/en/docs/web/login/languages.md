# Function Overview

The platform supports multiple interface languages, which can be switched at any time before or after login; the switch takes effect immediately.

1. Before login, switch the language through the icon in the upper right corner

   <img src="../../../../photo/docs/login/language.png" width="80%">

2. After login, switch the language next to the user in the upper right corner

   <img src="../../../../photo/docs/login/language2.png" width="80%">

Multi-language texts on the platform (for example the name of a measurement group or the name of a device parameter) are shown in the corresponding language when the interface language is switched; if a name is not filled in for that language, the default name is shown.
