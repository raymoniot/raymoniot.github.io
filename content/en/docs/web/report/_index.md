# Function Overview

The Report Center is used to view and export statistical data by time dimension, and is divided into two pages:

- **[Plant report]({{< ref "total" >}} "Summary Data")**: Statistics such as Power Generation and income by business type and plant
- **[Device report]({{< ref "total" >}} "Summary Data")**: Statistics of the operating data of devices by device type and Serial Number

Both pages support selecting the report type (day, month, year, total) and the time range, and the query results can be exported as an Excel sheet for reconciliation and reporting. Which plants and devices are visible in the report depends on the account's Data Permissions.
