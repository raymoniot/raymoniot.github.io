# Function Overview

The Work Order System is used to receive and handle problems raised by users, and consists of three parts:

- **[Work Order Dashboard]({{< ref "dashboard" >}} "Work Order Dashboard")**: overall processing status, today's trend, to-dos and score statistics
- **[Work Order List]({{< ref "list" >}} "Work Order List")**: details of all work orders, where you can change the status, modify and score them
- **[Customer Team]({{< ref "team" >}} "Customer Team")**: maintain the teams that handle work orders and their main members

A work order can be initiated from an event in the [Event Center]({{< ref "../events" >}} "Event Center"), a plant details page or a device details page, or submitted by end users in the App.
