# Function Overview

The Operation and Maintenance Center is used to track abnormal conditions occurring on the platform and turn them into work orders that can be followed up:

- **Event Center**: Summarizes the plants and devices that have alarmed on the platform. You can search events by conditions, and [create a work order]({{< ref "ticket/list" >}} "Work Order List") for a specific event
- **Work Order System**: Consists of the [Work Order Dashboard]({{< ref "ticket/dashboard" >}} "Work Order Dashboard"), the [Work Order List]({{< ref "ticket/list" >}} "Work Order List") and the [Customer Team]({{< ref "ticket/team" >}} "Customer Team") — the dashboard shows the overall processing status and trends, the list handles specific work orders, and the customer team decides who handles each work order

Events come from alarms and faults reported by devices; work orders can be initiated from an event, a plant or a device, or submitted by end users in the App. The two types of data are interrelated, making it easy to form a closed loop of "discover a problem → assign a work order → handle → score".
