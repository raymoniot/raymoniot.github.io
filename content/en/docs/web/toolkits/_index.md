# Function Overview

The Toolbox is designed for operation and debugging scenarios and provides the following tools:

- **Firmware Management**: maintain the OTA firmware of each device type, and perform access authorization and redemption code distribution
- **Batch Operation**: perform firmware upgrade, parameter settings and command transmission on multiple devices in batch, track them as tasks, and redo failed devices
- **Point Query**: query the latest reported measurement point data of a device by serial number, to troubleshoot device reporting
- **Remote Interaction**: send command transmission, parameter settings and firmware upgrade to a single collector, and view the operation log
- **Production Test**: perform production/factory test on devices according to the test standard, and automatically export the test report
- **Notice Announcement**: push announcement messages to the Web or App

Most operations in the Toolbox are delivered to real devices. Please make sure the selected devices are correct before executing.
