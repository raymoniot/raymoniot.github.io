# Function Overview

## 1. Device List

<img src="../../../../photo/docs/device/collector/device-list.png">

The device list can view online, faulty, offline and all device information.

<img src="../../../../photo/docs/device/collector/collector-uninstall.png">

<img src="../../../../photo/docs/device/collector/collector-install.png">

For collector devices, there are two additional states

- **Installed**: The collector is bound to a plant after entering the warehouse

- **Not Installed**: The collector is not bound to a plant after entering the warehouse

## 2. Collector entry

<img src="../../../../photo/docs/device/collector/import-one.png">

There are two ways to enter the collector

- Single import: import a single collector, import one collector at a time

- Batch import: import multiple collectors at one time by writing the collector SN into the template file

### 2.1 Single import

<img src="../../../../photo/docs/device/collector/import-one1.png" width="600" height="450">

Generally, select WI-FI Stick as the collector type. Fill in the authorized user to authorize the device to other users. The user has the right to view and manage the device. If it is not filled in, the current logged-in user will be used by default. Filling in the label will add notes to the collector.

### 2.2 Batch import

<img src="../../../../photo/docs/device/collector/import-more1.png" width="600" height="450">

Download the collector import template

<img src="../../../../photo/docs/device/collector/import-more.png">

You can fill in multiple collector SNs, Owner is the authorized user, Keywords is the tag

<img src="../../../../photo/docs/device/collector/import-more2.png" width="700" height="550">

Select WI-FI Stick as the type, upload and read the verification, and the addition will be successful. If the wrong SN is uploaded or the SN has been stored, an error message will be listed

## 8. Collector details page

<img src="../../../../photo/docs/device/collector/detail-enter.png">

You can enter the device details page from the device in the device list

<img src="../../../../photo/docs/device/collector/detail.png">

The collector details page includes the basic information of the collector and its sub-devices. The supported sub-devices include inverters, BMS, optimizers, meters, etc.

### 8.1 Alarm

<img src="../../../../photo/docs/device/collector/alert.png">

The alarm will open the device event page of the device, where you can see all the alarms generated by the device

<img src="../../../../photo/docs/device/collector/alert1.png">

### 8.2 Unbinding

<img src="../../../../photo/docs/device/collector/unbind.png">

The unbinding of the collector will unbind the plant bound to the collector. **The unbinding of the sub-device will delete the sub-device from the collector and clear the data of the sub-device**.
