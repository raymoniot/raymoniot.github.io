---
title: Device Center
description: The Device Center displays the added device data information for management. It supports device SN query, single import/batch import, device type/status filtering, device details, view the system to which it belongs, and delete device data. It is convenient for you to quickly import and manage the data of the collector or DTU data device. The supported device types include collectors, inverters, batteries, optimizers, meters, etc.
