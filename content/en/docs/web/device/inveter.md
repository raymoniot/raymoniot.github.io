### 3.8 Historical data chart

<img src="../../../../photo/docs/device/inveter/chart.png">

Historical data supports data display and time range selection at daily, weekly, monthly, annual and total levels, where different time dimensions display different parameters

- **Daily**: Users can customize parameter display through [parameter selection]({{< ref "/inveter/#381Parameter selection" >}} "Parameter selection")

- **Weekly**: Users can customize parameter display through [parameter selection]({{< ref "/inveter/#381Parameter selection" >}} "Parameter selection")

- **Month**: Display power generation

- **Year**: Display power generation

- **Total**: Display power generation
