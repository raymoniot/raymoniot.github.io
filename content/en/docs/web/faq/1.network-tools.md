# Function Overview

The network search configuration tool is mainly used to configure the WiFi stick (collector). Sending commands to the collector with the network search tool can modify the parameters of the collector.

The tool is a stand-alone program running on a PC (it is not a page of the platform). It is usually used for the configuration of a newly delivered collector and for on-site troubleshooting: first search for the collectors in the same network, then send AT commands to query or modify the configuration.

# How to use

## 1. Prerequisites

The PC that uses the network search tool must be in the **same network** as the collector, otherwise the collector cannot be found.

## 2. Search all collector devices in the current network

<img src="../../../../photo/docs/faq/1/1.png" width="700" height="550">

After the program is opened, the network search tool automatically takes the gateway address of the current network as the search address. Click the search button to search for collector devices.

## 3. Select a device and send commands

<img src="../../../../photo/docs/faq/1/2.png" width="700" height="550">

Select the target device; the list shows the IP address and the serial number of the collector.

<img src="../../../../photo/docs/faq/1/3.png" width="700" height="550">

After a command is sent, the execution result can be seen in the log: in the figure, `+ok` means the command was executed successfully, `=2` means the execution result of the command is 2, and the command executed in the figure queries the URL the collector reports data to, where the result 2 means configuration 2 is used.

**FAQ**:

- **No reply after sending a command**: sometimes there is no result in the log after a command is sent. In this case the communication between the network search configuration tool and the collector may be disconnected. Search for the device again and send the command again to solve it.
- **ERR returned after sending a command**: check whether the command format is correct and whether Chinese symbols were used by mistake; you can search for the device several times and try to send the command again.

# Common commands

## Query commands

- AT+SERVERSELECT: query the server selection, used to check whether the reported data server address points to 1 or 2 (the collector supports two address targets, URL1 and URL2; a result of 1 means address 1 takes effect, a result of 2 means address 2 takes effect)
- AT+SERVERURL1: query the content of URL1, usually in the format logger.example.com,5005
- AT+SERVERURL2: query the content of URL2, usually in the format logger.example.com,5005

## Setting commands

- AT+SERVERSELECT=1: change the server selection of the collector to URL1, so URL1 takes effect
- AT+SERVERSELECT=2: change the server selection of the collector to URL2, so URL2 takes effect
- AT+SERVERURL1=logger.example.com2,5005: change URL1 of the collector to logger.example.com2,5005
- AT+SERVERURL2=logger.example.com2,5005: change URL2 of the collector to logger.example.com2,5005

## Other commands

- AT+FSET: save the configuration
- AT+RST: restart the collector (the collector must be restarted for the changes of the target and configuration to take effect)
