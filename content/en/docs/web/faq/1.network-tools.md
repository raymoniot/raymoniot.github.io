# Function Overview

The network search configuration tool is mainly used to configure the WiFi data stick (collector). Using the network search tool to send commands to the collector can modify the parameters of the collector

# Usage

## 1. Prerequisites

The PC using the network search tool must be in the **same network** as the collector, otherwise the collector will not be searched

## 2. Search for all collector devices in the current network

<img src="../../../../photo/docs/faq/1/1.png" width="700" height="550">

After opening the software, the network search tool will automatically find the gateway address of the current network as the search address by default. Click the search button to search for collector devices

## 3. Select the device to send instructions

<img src="../../../../photo/docs/faq/1/2.png" width="700" height="550">

Select the target device, and you can see the IP address and serial number of the collector in the list

<img src="../../../../photo/docs/faq/1/3.png" width="700" height="550">

After sending the command, you can see the execution result of the command in the log. As shown in the figure, +ok means successful execution, =2 means the command execution result is 2. The command executed in the figure is to query the URL address of the data reported by the collector. The result 2 means that configuration 2 is used

**Common problems:**:

- **No return after sending the command**: After sending the command, there may be no return result in the log. At this time, it may be that the network search configuration tool is disconnected from the collector. You can solve it by searching the device again and resending the command

- **ERR after sending the command**: Check whether the command format is correct and whether the symbol is Chinese. You can search the device multiple times and resend the command to try

# Common commands

## Query command

- AT+SERVERSELECT: query server selection, used to check whether the reported data server address points to 1 or 2 (the collector supports configuring two addresses, URL1 and URL2. If the query is 1, address 1 will take effect, and if the query is 2, address 2 will take effect)
- AT+SERVERURL1: query the address content of URL1, generally in the format of logger.example.com,5005
- AT+SERVERURL2: query the address content of URL2, generally in the format of logger.example.com,5005

## Setting command

- AT+SERVERSELECT=1: modify the collector server selection, point to URL1, URL1 is effective
- AT+SERVERSELECT=2: modify the collector server selection, point to URL2, URL2 is effective
- AT+SERVERURL1=logger.example.com2,5005: modify the address of collector URL1 to logger.example.com2,5005
- AT+SERVERURL2=logger.example.com2,5005: Change the address of the collector URL2 to logger.example.com2,5005

## Other commands

- AT+FSET: Save configuration information
- AT+RST: Restart the collector (restart is required to take effect after modifying the collector's direction and configuration)
