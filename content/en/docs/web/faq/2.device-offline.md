# Function Overview

When the collector stays offline on the platform after installation and power-on, troubleshoot in the following order: first check the indicator lights of the device to make sure it starts normally, then use the network search configuration tool to check whether the server address configuration of the collector is correct.

# 1. Check the indicator light of the collector

After power-on, first observe the indicator lights on the device to make sure it is powered and started normally (the meaning of each indicator light is described in the manual delivered with the device). If the indicator lights are abnormal (for example nothing is lit), check the power supply and the wiring first, then continue with the configuration checks below.

# 2. Check the configuration with the network search configuration tool

For how to use the network search configuration tool, refer to [Network Search Tool]({{< ref "1.network-tools" >}} "Network Search Tool")

# 3. Checking steps

## 1. Query the server selection

<img src="../../../../photo/docs/faq/2/check1.png" width="700" height="550">

Send AT+SERVERSELECT to query the URL of the server selection. Firmware after version 3.0 points to URL2 by default, which is the address of the gateway service of each vendor; contact us if you are not clear about the address. As shown in the figure, a reply of ok=2 means the collector points to URL2.

## 2. Query the server address

<img src="../../../../photo/docs/faq/2/check2.png" width="700" height="550">

Send AT+SERVERURL2 to query the address of URL2. As shown in the figure, the address of URL2 is tt.raymoniot.com, which is the test environment of the platform.

## 3. Modify the server address

<img src="../../../../photo/docs/faq/2/check3.png" width="700" height="550">

If the address is not the address of your platform or is not as expected, you can modify it by sending AT+SERVERURL2=xxx.xxx.com

## 4. Save

<img src="../../../../photo/docs/faq/2/check4.png" width="700" height="550">

Send AT+FSET to save the configuration

## 5. Restart

<img src="../../../../photo/docs/faq/2/check5.png" width="700" height="550">

Send AT+RST to restart the collector for the change to take effect; after the restart you can check whether the device is online on the platform.

After the address is confirmed to be correct and the device is restarted, the device usually reports data and shows online on the platform within a few minutes; if it is still offline, please feed back the device serial number together with the query results above to us.
