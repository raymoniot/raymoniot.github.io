# 1. Check the collector signal light

# 2. Use the network search configuration tool to check the configuration

For the usage of the network search configuration tool, refer to [Network Search Configuration Tool]({{< ref "1.network-tools" >}} "Network Search Configuration Tool")

# 3. Check method

## 1. Query server selection

<img src="../../../../photo/docs/faq/2/check1.png" width="700" height="550">

Send AT+SERVERSELECT command to query the URL selected in the service area. The firmware after version 3.0 points to URL2 by default, which is the address of each gateway service. If the address is unclear, please contact us. If the figure returns ok=2, it means that the collector points to URL2

## 2. Query server address

<img src="../../../../photo/docs/faq/2/check2.png" width="700" height="550">

Send AT+SERVERURL2 to query the URL address. As shown in the figure, the URL2 address is tt.raymoniot.com, which is the test environment of the platform

## 3. Modify the server address

<img src="../../../../photo/docs/faq/2/check3.png" width="700" height="550">

If the address is not your platform address or does not meet expectations, you can send AT+SERVERURL2=xxx.xxx.com to modify it

## 4. Save

<img src="../../../../photo/docs/faq/2/check4.png" width="700" height="550">

Send AT+FSET to save the configuration

## 5. Restart

<img src="../../../../photo/docs/faq/2/check5.png" width="700" height="550">

Send AT+RST to restart the collector to take effect. After restarting, you can observe whether the device is online on the platform.
