# Function Overview

The Commercial Plant page is used to manage plants whose business type is Commercial Plant (EMS). Its page structure is exactly the same as the [PVS]({{< ref "/pvs" >}} "PVS"): the plant overview is at the top, the plant list and plant map are below, you can add a plant and enter the System large screen in the upper right corner, and click a plant to enter its details page.

For the specific description of each section, please refer to the corresponding chapter; this section only lists the differences from the PVS and Residential Storage.

## Plant Overview

This is the same as the Residential Storage, for details please refer to [Plant Overview]({{< ref "/hess#plant-overview" >}} "Residential Storage")

## Plant List

This is the same as the photovoltaic system, for details please refer to [Plant List]({{< ref "/pvs#plant-list" >}} "PVS")

## Plant Map

This is the same as the photovoltaic system, for details please refer to [Plant Map]({{< ref "/pvs#plant-map" >}} "PVS")

## System large screen

## Plant details page

This is the same as the Residential Storage, for details please refer to [Plant details page]({{< ref "/hess#plant-details-page" >}} "Residential Storage")
