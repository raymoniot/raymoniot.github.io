## 1. Add a collector entry

Enter the [Power Station Details Page]({{< ref "/pvs/#Power Station Details Page" >}} "Power Station Details Page") of the power station from the power station list, and add a collector in the upper right corner

![psv-overview](../../../../photo/docs/add-logger/add-logger-enter.png)

## 2. Function Overview

- ### 2.1 Enter the collector serial number to add

<img src="../../../../photo/docs/add-logger/add-one1.png" width="550" height="400">

Add a serial number. Before adding, you must first [Enter the Collector]({{< ref "../device/collector/#2Enter the Collector" >}} "Collector into the library"), if already in the library, ignore

<img src="../../../../photo/docs/add-logger/add-one2.png" width="550" height="400">

Click the Submit button to complete the collector addition

<img src="../../../../photo/docs/add-logger/add-one3.png" width="550" height="400">

- ### 2.2 Add through template file

Download template collector-import-template.xlsx

<img src="../../../../photo/docs/add-logger/add-more1.png" width="550" height="400">

Add serial number in the template

<img src="../../../../photo/docs/add-logger/add-more.png" width="550" height="400">

Add via template file

<img src="../../../../photo/docs/add-logger/add-more2.png" width="550" height="400">

Submit after confirmation

<img src="../../../../photo/docs/add-logger/add-more3.png" width="550" height="400">
